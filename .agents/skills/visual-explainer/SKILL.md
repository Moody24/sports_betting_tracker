# Visual Explainer for Edge Tracker

Local HTML-only adaptation of nicobailon/visual-explainer at
`33a6b4d43958d2d152c9cb13762af802062fade5`.

Create one self-contained local HTML page with inline CSS and SVG. Lead with a
readable diagram, label arrows with actual behavior, and link each current-system
claim to inspected source at the revision used. Show proposals separately from
verified behavior. Keep text and diagrams accessible at mobile width, in print,
and with keyboard navigation. Use local fonts or system fonts and no CDN.

Do not convert ordinary tables to HTML automatically. Do not use upstream
renderers, video, narration, slides, image generation, MCP extensions, paid APIs,
third-party diagram uploads, or install dependencies. Keep the result local
unless the owner separately asks to publish it.
