# Verified lessons

Add a lesson only when a check or incident supports it. Link the evidence and
state when to recheck. Do not turn an isolated observation into a universal
rule, and do not copy raw transcripts or private data here.

| Observation | Evidence | Recheck trigger |
| --- | --- | --- |
| A repository-local plugin disable does not prove every client catalog hides the same global skill. | [Stack activation limits](codex-stack.md#compatibility-and-history) from local CLI diagnostics. | Codex client or plugin configuration changes. |
| A focused contract-test pass does not establish an application-suite pass. | [Workflow verification rule](coding-workflow.md#one-review-cycle). | Before a release or when test environment changes. |
